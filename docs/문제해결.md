# 잘 안 될 때

## 설치·실행

**`findpic` 이 없는 명령이라고 나옵니다**

파이썬의 `Scripts` 폴더가 PATH 에 없어서입니다. 이렇게 실행해도 똑같이 동작합니다.

```
python -m findpic
```

**파이썬을 설치했는데 `python` 이 인식되지 않습니다**

설치할 때 "Add Python to PATH" 를 체크하지 않은 경우입니다.
파이썬을 다시 설치하면서 그 항목을 체크하거나, 윈도우 스토어에서 Python 을 설치하세요.

**한글이 깨져 보입니다**

명령 프롬프트에서 아래를 먼저 실행해 보세요.

```
chcp 65001
```

윈도우 터미널(Windows Terminal)을 쓰면 이 문제가 없습니다.

## 한글 파일 읽기

**"OLE 복합 문서로 열 수 없습니다" 라고 나옵니다**

한글 3.x 시절 파일이거나 확장자만 `.hwp` 인 다른 파일입니다.
한글에서 열어 `한글 문서 (*.hwp)` 로 다시 저장하면 읽을 수 있습니다.

**"암호가 걸린 한글 파일입니다"**

암호를 풀어 저장한 뒤 다시 실행해 주세요.

**표에서 사진을 찾지 못했다고 합니다**

- 사진이 표 밖에 놓여 있으면 `--include-floating` 을 붙여 보세요.
- 사진이 너무 작으면(가로나 세로가 200픽셀 미만) 아이콘으로 보고 건너뜁니다.
- `findpic scan --hwp "파일.hwp"` 로 무엇이 보이는지 먼저 확인해 보세요.

**이름이 엉뚱하게 붙습니다**

`findpic scan` 의 `이름 출처` 를 보면 어느 칸에서 가져왔는지 알 수 있습니다.
사진 칸과 열 병합 범위가 같은 칸을 이름으로 쓰므로, 표 서식이 특이하면 빗나갈 수 있습니다.
그런 표가 있으면 알려 주세요.

## 원본 찾기

**'확인 필요' 가 너무 많습니다**

검토 리포트를 열어 어떤 이유인지 보세요. 흔한 경우는 이렇습니다.

- *비슷한 사진이 여럿입니다* — 연사로 찍은 사진들입니다. 눈으로 고르는 게 빠릅니다.
- *EXIF 는 같은데 사진이 달라 보입니다* — 원본을 편집해 다른 사진에 덮어썼을 수 있습니다.
- *닮긴 했지만 확신할 수 없습니다* — 보고서에 넣을 때 잘라 넣었을 가능성이 큽니다.

**'못 찾음' 이 많습니다**

- `--source` 에 원본 폴더를 빠뜨리지 않았는지 확인하세요. 여러 번 쓸 수 있습니다.
- 원본이 RAW 뿐이라면 EXIF 로만 맞춥니다. 저용량 사진에 EXIF 가 없으면 찾지 못합니다.
- 지도·도면처럼 카메라로 찍지 않은 그림은 원본이 사진 폴더에 없는 게 정상입니다.
  이런 것들은 한글 파일 안의 저용량 그림이 대신 들어갑니다.

**엉뚱한 사진을 가져왔습니다**

`_findpic\결과목록.csv` 의 `가져온곳` 으로 어느 파일인지 확인하고 알려 주세요.
`--strict` 를 쓰면 '확실' 로 판정된 것만 원본으로 취급합니다.

## 속도·용량

**원본 폴더 훑기가 너무 오래 걸립니다**

처음 한 번만 오래 걸립니다. 결과는 `--cache` 위치(기본값은 결과 폴더 안 `.findpic`)에
저장되어 다음부터는 바뀐 파일만 다시 읽습니다.
`--workers 16` 처럼 올리면 더 빨라질 수 있습니다(SSD 기준).

**검토 리포트 파일이 너무 큽니다**

문서가 60개를 넘으면 확인이 필요한 것에만 큰 썸네일을 넣습니다.
`--thumbs attention` 을 직접 지정하면 더 작아지고, `--no-report` 면 만들지 않습니다.

**"no space left on device"**

색인 파일과 복사한 사진이 공간을 씁니다. `--dry-run` 으로 얼마나 넣을지 먼저 확인해 보세요.
