# findpic — 한글 보고서 사진, 원본 찾아 정리하기

보고서에 넣을 때는 용량을 줄인 사진을 쓰고, 제본할 때는 원본이 필요합니다.
그런데 정리해 둔 원본 폴더가 날아가면, 보고서에 박힌 저용량 사진과 원본 수만 장을
눈으로 하나씩 맞춰 봐야 합니다.

`findpic` 은 그 일을 대신합니다.

한글 파일(`.hwp` / `.hwpx`)의 **표 안에 들어간 사진**과 **그 사진에 붙은 이름**을 읽어내고,
원본 사진 폴더에서 같은 사진을 찾아, 표에 적힌 이름으로 바꿔 폴더에 넣어 줍니다.

```
보고서.hwp 의 표                    원본 사진 폴더            정리된 폴더
┌──────────┬──────────┐            E:\사진\2025\...          대전_026\
│  [사진]  │  [사진]  │   ──▶      DSC_1043.JPG      ──▶     ├─ 항공사진.JPG
├──────────┼──────────┤            DSC_1044.JPG             ├─ 전경.JPG
│ 항공사진 │   전경   │            DSC_1101.JPG             ├─ 근경.JPG
└──────────┴──────────┘            ... 30,000장             └─ 확인 유물.JPG
```

---

## 어떻게 찾아내는가

**1. EXIF 지문 (가장 확실)**

한글은 사진을 줄여 넣어도 사진기가 기록한 정보를 그대로 남깁니다.
촬영 시각이 1/100초 단위까지 남아 있어, 원본이 몇 만 장이든 정확히 한 장을 집어냅니다.

```
항공사진  →  Hasselblad L1D-20c · 2025-09-04 11:10:19
근경      →  NIKON D5500       · 2025-09-04 11:16:16.59
```

**2. 겉모습 지문 (EXIF 가 지워진 사진용)**

지도·도면처럼 EXIF 가 없는 그림은 사진 자체를 비교합니다.
아주 작게 줄인 뒤의 밝기·색 배치를 보기 때문에, 크기를 줄이고 다시 압축해도, 돌려 넣어도 찾아냅니다.

**3. 접전이면 다시 확인**

1등과 2등이 붙어 있으면 원본 화소를 크게 읽어 다시 비교합니다.
등고선만 같고 표시 하나가 다른 지형도 두 장처럼, 거의 똑같은 그림도 갈라냅니다.

**4. 한글이 적어 둔 원본 파일 이름**

셀에 그림을 얹은 경우, 한글은 개체 설명문에 원래 파일 이름과 화소 크기를 적어 둡니다.
그것도 단서로 씁니다.

세 갈래가 서로 어긋나면 **확인 필요** 로 표시해 사람에게 넘깁니다. 조용히 틀리지 않습니다.

**5. 같은 사진이 여러 판본이면 가장 큰 것**

원본 사진 폴더에는 보고서용으로 줄여 둔 사본이 함께 남아 있는 경우가 많습니다.
그 사본은 한글에 든 사진과 화소까지 같아서 점수가 가장 높게 나오지만,
제본에 필요한 것은 큰 원본입니다.

그래서 같은 사진임을 알아보고 **그중 가장 큰 것**을 고릅니다.
크기가 비슷한 것끼리는 갈아타지 않습니다 — 거의 똑같아 보이는 다른 사진일 수 있으니까요.

```
E:\사진원본\DSC_1043.JPG            4968×3306  3.3MB   ← 이것을 고릅니다
E:\사진원본\보고서용\DSC_1043.jpg     828×551   193KB   (한글에 든 것과 같은 사본)
```

줄인 사본밖에 없으면 **확인 필요** 로 표시하고 이렇게 알려 줍니다.

> 한글에 든 사진과 완전히 같은 파일입니다. 원본이 아니라 보고서용으로 줄인 사본으로 보입니다.

결과 목록과 검토 리포트에 **한글 속 사진의 몇 배 크기인지**가 함께 나옵니다.
1.2배가 안 되면 빨간색으로 보입니다.

## 이름은 어떻게 정하는가

표에서 **사진 칸과 열 병합 범위가 정확히 같은 칸**의 글을 이름으로 씁니다.
아래 칸을 먼저 보고, 없으면 위 칸을 봅니다.

```
┌───────── 사진 (5칸 병합) ─────────┐
├───────── 항공사진 (5칸 병합) ─────┤   ← 폭이 같다. 이름이다.

┌───────── 사진 (5칸 병합) ─────────┐
├─ 현상보존 (3칸) ─┼─ 시굴조사 ─────┤   ← 폭이 다르다. 이름이 아니다.
```

같은 이름이 여러 번 나오면 번호를 붙입니다.

```
항공사진, 전경, 근경(1), 근경(2), 유물사진
```

원본을 못 찾은 사진은 **한글 파일 안의 저용량 사진이라도** 같은 이름으로 넣습니다.
폴더가 비지 않도록. 어느 것이 저용량인지는 결과 목록과 검토 리포트에 남습니다.

## 가장 빠른 길 (윈도우)

창이 뜨는 프로그램으로 쓰려면 두 가지 중 하나를 고르세요.

**A. 지금 바로 쓰기** — 파이썬이 깔려 있으면 이것으로 충분합니다.

`scripts` 폴더의 **`사진찾기(창).bat`** 을 두 번 누르세요.
처음 한 번만 필요한 것을 설치하고, 그다음부터는 바로 창이 뜹니다.

**B. 바탕화면에 두고 쓰기** — 파이썬이 없는 컴퓨터에도 넘겨줄 수 있습니다.

`scripts` 폴더의 **`바탕화면에 만들기.bat`** 을 두 번 누르세요. 그러면

1. 필요한 것을 설치하고
2. `사진찾기.exe` 를 만들고
3. **바탕화면에 놓아 줍니다** (OneDrive 로 옮겨진 바탕화면도 찾습니다)

처음에는 3-10분쯤 걸립니다. 끝나면 바탕화면이 열리고 아이콘이 보입니다.
그 exe 하나만 있으면 되고, 이 폴더는 지워도 됩니다.

> **처음 실행할 때** 윈도우가 "PC를 보호했습니다" 라며 막을 수 있습니다.
> 서명하지 않은 프로그램이라 그런 것입니다. **추가 정보 → 실행** 을 누르면 됩니다.
> 한 번만 하면 그다음부터는 묻지 않습니다.

> exe 는 만든 운영체제에서만 돌아갑니다. 윈도우용 exe 는 윈도우에서 만들어야 합니다.

창은 이렇게 생겼습니다.

```
┌─ 한글 보고서 사진 원본 찾기 ───────────────────────────────┐
│  1. 한글 파일 또는 폴더  [D:\보고서5 ...] [폴더][파일] │
│  2. 원본 사진 폴더       [E:\사진원본5 ]  [추가][빼기] │
│                          [E:\사진원본\드론  ]              │
│  3. 정리해 넣을 폴더     [D:\정리\대전     ]  [폴더]        │
│                                                             │
│  [ ] 실제로 넣지 않고 무엇이 어디로 갈지만 확인 (미리보기)  │
│  [ ] '확인 필요' 로 판정된 것은 원본으로 치지 않기          │
│  원본을 못 찾으면  [같은 이름으로 그대로 넣기        ▾]     │
│                                                             │
│  [  시작  ] ▓▓▓▓▓▓▓▓░░░░░░░░░  [중단]                       │
│  대조 중  786 / 1,247 · 항공사진                            │
│  ● 한글 파일 218개를 읽습니다.                              │
│    표에서 사진 1,247장과 이름을 찾았습니다.                 │
│  ...                                                        │
│  [검토 리포트 열기]  [결과 폴더 열기]                       │
└─────────────────────────────────────────────────────────────┘
```

경로는 한 번 넣으면 기억합니다. 중간에 **중단**을 눌러도 지금까지 만든 색인은 남아
다시 실행하면 이어서 합니다.

## 설치

파이썬 3.9 이상이 필요합니다.

```bash
pip install git+https://github.com/lzpxilfe/find-picture-from.git
```

내려받아 설치하려면:

```bash
git clone https://github.com/lzpxilfe/find-picture-from.git
cd find-picture-from
pip install -e .
```

아이폰 사진(HEIC)도 다루려면:

```bash
pip install "findpic[heic] @ git+https://github.com/lzpxilfe/find-picture-from.git"
```

윈도우에서는 `scripts` 폴더의 `설치.bat` 을 두 번 눌러도 됩니다.

## 쓰는 법 (명령줄)

창 대신 명령줄로도 똑같이 쓸 수 있습니다.

### 그냥 실행하기 (묻고 답하는 방식)

```bash
findpic
```

```
  ┌───────────────────────────────────────────────┐
  │  한글 보고서 사진 → 원본 사진 찾아 정리하기   │
  └───────────────────────────────────────────────┘

  경로는 탐색기에서 파일/폴더를 이 창에 끌어다 놓으면 자동으로 입력됩니다.

  1) 한글 파일 또는 한글 파일들이 든 폴더 : D:\보고서
  2) 원본 사진이 들어 있는 폴더           : E:\사진원본
  3) 정리해 넣을 폴더                     : D:\정리
```

## 이미 한 번 돌렸는데 다시 하려면

**덮어쓰기**를 켜고 다시 돌리면 됩니다. 창에서는 "이미 있는 파일 덮어쓰기" 를 체크하고,
명령줄이면 `--overwrite` 를 붙입니다.

확장자가 달라진 옛 파일(`항공사진.jpg` → `항공사진.JPG`)도 함께 치우므로,
같은 이름이 두 개 남는 일이 없습니다. 원본 사진 폴더는 건드리지 않습니다.

## 결과 확인

`_findpic\검토리포트.html` 을 브라우저로 열면, 한글 파일 속 사진과 찾아낸 원본이
나란히 놓입니다. 위쪽 단추로 **확인 필요** 만 골라 볼 수 있습니다.

`_findpic\결과목록.csv` 는 엑셀에서 바로 열립니다.

| 한글파일 | 사진이름 | 판정 | 점수 | 크기배수 | 넣은파일 | 가져온곳 | 종류 |
|---|---|---|---|---|---|---|---|
| 대전_026.hwp | 항공사진 | 확실 | 0.986 | 36.0배 | 대전_026\항공사진.JPG | E:\사진\DSC_1043.JPG | 원본 |
| 대전_026.hwp | 기존 | 확인필요 | 0.712 | | 대전_026\기존.jpg | 대전_026.hwp 안 | 저용량 |

### 틀린 것 고치기

리포트에서 '확인 필요' 인 줄에는 후보들이 나란히 놓입니다.
맞는 것을 고르고(맞는 원본이 없으면 그렇게 고르고) 아래쪽 단추를 누르면
`수정목록.csv` 가 내려받아집니다. 그 파일로 이렇게 다시 넣습니다.

```bash
findpic apply --csv "수정목록.csv"
```

어디에 무엇을 넣었는지는 `_findpic\상태.json` 에 남아 있어, 결과 폴더만 있으면
언제든 다시 고칠 수 있습니다. `--dry-run` 을 붙이면 계획만 보여 줍니다.

## 폴더는 어떻게 맞추는가

이미 만들어 둔 폴더가 있으면 거기에 넣습니다. 이 순서로 찾습니다.

1. 한글 파일 이름과 같은 폴더
2. 문서의 `도면 명칭` · `유적명` 값과 같은 폴더
3. 폴더 이름이 한글 파일 이름 안에 들어 있는 경우
4. 이름이 비슷한 폴더

맞는 폴더가 없으면 한글 파일 이름으로 새로 만듭니다.
새로 만들지 않으려면 `--no-create-missing` 을 붙입니다.

## 자주 쓰는 선택지

| 선택지 | 하는 일 |
|---|---|
| `--dry-run` | 실제로 넣지 않고 계획만 보여 줍니다 |
| `--strict` | '확인 필요' 는 원본으로 치지 않습니다 |
| `--allow-same-size` | 한글 속 사진과 크기가 비슷한 파일도 그냥 원본으로 인정합니다 |
| `--lowres suffix` | 저용량 사진에 `(저용량)` 표시를 붙입니다 |
| `--lowres subdir` | 저용량 사진을 `_저용량` 폴더에 따로 넣습니다 |
| `--lowres skip` | 원본을 못 찾으면 아무것도 넣지 않습니다 |
| `--name "{도면명칭}_{이름}"` | 파일 이름 서식을 바꿉니다 |
| `--flat` | 문서별 폴더를 나누지 않고 한 곳에 모읍니다 |
| `--include-floating` | 표 밖에 놓인 사진도 대상에 넣습니다 |
| `--source` 를 여러 번 | 원본 폴더를 여러 곳 지정합니다 |
| `--workers 16` | 사진을 더 많이 동시에 읽습니다 (기본값은 이 컴퓨터의 코어 수) |
| `--no-fast-index` | EXIF 축소판을 쓰지 않고 사진 파일 전체를 읽습니다 |

파일 이름 서식에 쓸 수 있는 것: `{이름}` `{구역}` `{번호}` `{파일명}` `{도면명칭}`,
그리고 그 문서 표의 머리글 이름(`{유적명}`, `{소재지}` 등).

## 안전 장치

- 원본 사진은 **읽기만** 합니다. 옮기거나 지우지 않습니다.
- 이미 있는 파일은 덮어쓰지 않고 `-2`, `-3` 을 붙입니다 (`--overwrite` 로 바꿀 수 있음).
- 색인은 저장해 두므로, 중간에 끊겨도 다시 실행하면 이어서 합니다.
- 한 원본이 두 자리를 차지하지 않게 정리합니다 (`--allow-duplicate` 로 끌 수 있음).
- 한 파일이 잘못돼도 나머지는 계속 처리합니다.

|---|---|

| 한글 `.hwpx` | 읽습니다 |

| 암호가 걸린 파일 | 건너뛰고 알려 줍니다 |
| 한글 3.x (아주 오래된 `.hwp`) | 읽지 못합니다. 한글에서 다시 저장해 주세요 |

원본 사진은 JPEG · PNG · TIFF · BMP · GIF · WebP 와
RAW(NEF · CR2 · ARW · DNG · ORF · RW2 등)를 다룹니다.
RAW 는 EXIF 로 맞춥니다. HEIC 는 `pip install pillow-heif` 를 하면 함께 다룹니다.

---

## 얼마나 걸리는가

원본 사진을 처음 훑을 때가 대부분입니다. 그 뒤로는 저장해 둔 색인을 씁니다.

사진기가 넣어 둔 EXIF 축소판이 있으면 파일 앞부분만 읽고 지나갑니다.
2.7MB 사진 한 장 기준 39ms → **3ms** 로 13배 빨랐습니다(4코어 실측).
축소판으로 만든 지문은 본체로 만든 것과 사실상 같습니다(정규화 상관 0.999 이상).
사진을 편집해 축소판이 옛것으로 남았을까 걱정되면 `--no-fast-index` 를 쓰세요.

| 원본 사진 | 처음 색인 | 두 번째부터 |
|---|---|---|
| 1,000장 | 몇 초 | 1초 미만 |
| 10,000장 | 1분 안팎 | 1초 안팎 |
| 50,000장 | 몇 분 | 몇 초 |

메모리는 사진 1장당 3KB 남짓입니다 (5만 장에 150MB, 20만 장에 600MB).
사진 대조 자체는 1장당 40ms 안팎입니다.

## 만들어진 구조

```
src/findpic/
  pipeline.py   찾아서 정리하는 전체 흐름 (창과 명령줄이 함께 쓴다)
  cli.py        명령줄
  gui.py        창 (tkinter, 따로 설치할 것 없음)
  hwp/          한글 파일 읽기 (HWP 5.x 바이너리, HWPX)
  imaging/      EXIF, 겉모습 지문, 이미지 열기
  index.py      원본 사진 색인 (SQLite 에 저장)
  match.py      대조와 판정
  caption.py    표에서 이름 찾기
  organize.py   폴더 정하기, 복사, 결과 기록
  report.py     검토 리포트
```

## 개발

```bash
pip install -e ".[dev]"
pytest
```

리눅스에서 창까지 시험하려면 `python3-tk` 가 필요합니다.
없으면 창 관련 검사 하나만 건너뜁니다.
